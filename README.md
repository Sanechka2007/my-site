# Персональный сайт-визитка — Зайцев Александр

Минималистичный одностраничный сайт-визитка с тёмной цветовой палитрой, интерактивной витриной любимых игр и мгновенным переключением языков без перезагрузки страницы.

## Основные возможности

* **Двуязычный интерфейс (RU / EN).** Мгновенный перевод всех элементов страницы, включая заголовки, описание и всплывающие подсказки у карточек игр.
* **Интерактивная витрина игр.** Галерея обложек любимых игр с плавным появлением всплывающего окна с описанием при наведении курсора.
* **Адаптивная вёрстка.** Корректное отображение на компьютерах, планшетах и смартфонах благодаря гибким сеткам Flexbox и динамическим размерам шрифтов (`clamp`).
* **Чистый стек без зависимостей.** Сайт написан на чистом HTML, CSS и Vanilla JavaScript без использования тяжелых фреймворков и сборщиков.

## 🛠 Технологии

* **HTML5** — семантическая разметка страницы.
* **CSS3** — CSS-переменные, Flexbox, плавные анимации (`transition`) и стилизованные тултипы.
* **JavaScript (ES6)** — динамическая смена языка и работа с `data-*` атрибутами.
* **Google Fonts** — шрифты *Inter* и *JetBrains Mono*.
